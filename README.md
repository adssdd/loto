# Guideline Book Builder

Небольшое веб-приложение для сети кофеен.

## Что делает
- принимает «сырое» сообщение с мыслями;
- разбивает текст на понятные пункты;
- автоматически распределяет пункты по разделам;
- раскладывает пункты по страницам мини-книги.

## Запуск
```bash
npm start
```

После запуска откройте `http://localhost:8000`.

> Сервер поддерживает fallback на `index.html` для неизвестных путей, поэтому превью больше не должно падать с `NotFound`.
